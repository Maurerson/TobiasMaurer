# TobiasMaurer

Persönliche Webseite von Tobias Maurer, IT-Helfer aus dem St. Galler Rheintal.

Live: https://maurerson.github.io/TobiasMaurer/

- `index.html` – die ganze Seite (Farben zentral oben im `<style>` unter `:root`)
- `assets/fonts` – Schriften liegen selbst hier (Schibsted Grotesk, Fraunces, Caveat; alle SIL Open Font License), keine Verbindung zu Google
- `assets/img` – Foto und Vorschaubild für Facebook/WhatsApp (`og.jpg`)
- `steckbrief/` – Vorlage und fertiges Bild für den Facebook-Steckbrief (1080×1350)

Die Webseiten-Entwürfe für Kunden liegen weiterhin im Repo `Demo`.
